# 第四批账户与会员 UI 需求

Owner B；用户2026-10-28授权。页面投影与输入边界待A/C评审，不表示正式认证/会员已完成。

| ID | UI需求 | 开发验收 |
| --- | --- | --- |
| UI-ACCOUNT-001 | 登录与安全返回 | 登录表单支持错误提示与站内返回；拒绝站外、编码、控制字符、管理路径和重复未知返回参数。 |
| UI-ACCOUNT-002 | 注册表单 | 姓名/邮箱/演示密码必填、长度/邮箱格式和重复一致校验；成功只产生本会话姓名邮箱预览，失败400保留非秘密输入。 |
| UI-ACCOUNT-003 | 密码边界 | 不验证真实密码、不保存/回显/发送密码；错误与成功均清空密码字段，Gateway不接触密码，不设置SecurityContext或角色。 |
| UI-ACCOUNT-004 | 个人中心 | 展示本会话资料，提供会员/我的预订入口；其他会话不可访问，退出只清理展示资料，保留其他模块状态。 |
| UI-ACCOUNT-005 | 会员状态 | 未开通/有效/过期/待确认可只读展示；不硬编码费用、折扣或实际资格，不因切换示例而激活。 |
| UI-ACCOUNT-006 | 开通续费入口 | 经登录页面预览后可回到原开通/续费位置；费用等待服务，支付按钮禁用，无付款或激活POST。 |
| UI-ACCOUNT-007 | 本地隔离与安全 | 默认入口关闭，仅回环dev account-ui启用；CSRF、no-store、文本转义、Session隔离和ID轮换保留。 |
| UI-ACCOUNT-008 | 视觉与适配交接 | 沿用批准的摄影/暖白/细线；桌面双栏/手机单列无溢出，明确A/C接入点和未完成项。 |

当前256字符密码上限只用于演示传输，不定义生产密码强度；正式策略需A确认。未实现真实账号存储、密码哈希/认证/找回、真实注册/登录/退出、会员资格/费用/折扣计算、付款或邮件。
