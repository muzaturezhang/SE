| ID | 需求 | 验收条件 |
| --- | --- | --- |
| FR-ROOM-007 | 管理列表 | STAFF 可查看具体房号、房型、启用状态和当前/未来占用标记；按房型/启用状态筛选，有明确空状态。 |
| FR-ROOM-008 | 新增房间 | 房号符合已登记格式且唯一；房型存在；新增启用房间即时进入查询，停用房间不进入查询。并发重复新增只有一次成功。 |
| FR-ROOM-009 | 修改与重新启用 | 保留固定房号，修改已有房型和启用状态；无占用时成功并反映在查询中，伪造表单房号不能重命名。 |
| FR-ROOM-010 | 安全停用 | 不物理删除房间或历史记录；有当前/未来有效占用则拒绝停用和更换房型；当日退房的旧占用不阻止操作。 |
| FR-ROOM-011 | 房型基础价 | 同房型共用基础价，CNY 精确转换为正整数分；拒绝额外小数、无效数值和溢出；前台立即显示更新。 |
| FR-ROOM-012 | 权限与 CSRF | 匿名/CUSTOMER 不能读写管理页面；STAFF 缺 CSRF 的 POST 仍拒绝。默认环境没有预览账号。 |
| FR-ROOM-013 | 原子失败与反馈 | 校验/冲突失败不提交任何修改；非法输入 400、冲突 409、找不到记录 404；成功重定向，错误与空状态可读。 |
