# 酒店官网风格候选

2026-10-27，用户认为当前 UI 风格过于像 AI 模板，要求先提供真实商业酒店官网供选择，再参考选定网站重做。当前首页只是开发模块入口，不能作为最终客户首页。

| 选项 | 官方参考 | 建议借鉴的方向 |
| --- | --- | --- |
| 1 | [Aman 安缦](https://www.aman.com/) | 安静的奢华度假体验；摄影、留白、细致排版和克制的预订入口 |
| 2 | [Six Senses 六善](https://www.sixsenses.com/en/) | 自然度假体验；景观、住宿介绍和清晰的日期及房间查询 |
| 3 | [Four Seasons 四季](https://www.fourseasons.com/) | 经典商业酒店体验；导航、房价查询、客房信息层级 |
| 4 | [The Hoxton](https://thehoxton.com/) | 有个性的精品酒店体验；编辑式布局、鲜明字体和预订入口 |

用户已于 2026-10-27 选择 1，即 Aman 安缦作为主参考。其余选项保留为选择记录。四个官方首页已通过网络搜索与网页读取确认；浏览器读取官网截图时超时，未保存或声称取得当前官网截图。

已按选择建立首页和客房页设计预览，规范见 `ui-design.md`。页面使用项目自己的品牌、文案和独立图库素材，保留现有后端架构与成员边界。
