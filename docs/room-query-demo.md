# 房间查询演示与数据说明

启动：`./scripts/dev.sh`，打开 `/rooms`。默认 dev/test 使用内存 Repository，数据读取自 `data/fixtures/room-inventory.json` 并打包到 JAR。数据只读，重复查询不会减少房间；本批没有创建、锁定、支付或管理写操作。

## 样例目录

| 房型 ID | 名称 | 每间每晚基础价 | 可售房间 |
| --- | --- | --- | --- |
| courtyard | 庭院客房 | CNY 980.00，98000 分 | C101 至 C104；C105 停用 |
| terrace | 露台套房 | CNY 1680.00，168000 分 | T201、T202 |
| pool | 泳池别墅 | CNY 3280.00，328000 分 | P301 |

价格和房间只是开发样例。会员折扣、订单总价、价格锁定与最终支付由 A/C 对接，不由查询页面计算。

## 可重复演示的日期

记应用启动当天（Asia/Shanghai）为 D。占用区间以这个日期为基准加载一次，重启重新生成相同的相对场景。

| 输入 | 预期结果 |
| --- | --- |
| D+2 入住、D+4 退房、1 间、全部房型 | 庭院客房 2 间可用；其他房型不满足整个期间连续可用 |
| D+4 入住、D+6 退房、1 间、全部房型 | 庭院 2 间、露台 2 间、泳池 1 间 |
| D+2 入住、D+6 退房、2 间、全部房型 | 无结果；各晚可用数量不能替代同一间房连续可用 |
| D+10 入住、D+12 退房、1 间、全部房型 | 庭院 4 间、露台 2 间、泳池 1 间；停用房 C105 不计入 |
| 过去日期、退房不晚于入住、数量 0/负数/小数/非数字、未知房型 | 后端返回 400 和可读提示 |

例如 D 为 2026-10-27 时，第一行日期为 2026-10-29 至 2026-10-31；第三行是 2026-10-29 至 2026-11-02。

## 适配边界

RoomInventory 检查重复 ID 和悬空引用，提供不可变快照。查询服务只依赖 RoomRepository 和共享 Clock。当前内存实现仅在 dev/test 且未开启 mysql 时注册；MySQL profile 需要 D 提供 Repository 实现，否则会因缺少 bean 而拒绝启动，避免误用样例库存。

页面通过服务器渲染数据和查询结果；JavaScript 仅辅助日期输入、触发 GET 房型筛选、控制导航与详情弹窗。关闭 JavaScript 仍能提交完整日期查询，后端校验不依赖浏览器。
