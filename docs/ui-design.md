# 客户界面设计基线

2026-10-27，用户从候选中明确选择 1，即 [Aman 安缦官网](https://www.aman.com/)，作为视觉主参考。

本轮首页与客房页重做后，用户表示“我觉得目前这个可以”。当前视觉方向已获用户认可，后续沿用并补功能；此认可不代表整个系统的 UI 或业务功能已经完成。

## 采用的设计方向

- 暖白底色 `#f3eee7`，深灰文字 `#313131`，细边框与克制的间距。
- 居中 Holiday Resort 文字标识，左侧探索导航，右侧客房与预订入口。
- 大幅度假摄影，少量图片说明；页面按住宿体验组织，不展示开发分工。
- 标题采用系统衬线字体，正文使用系统无衬线字体；没有下载参考网站的商业字体。
- 按图片和文字的编辑式布局展示居所，避免模块看板式卡片。
- 桌面与手机布局共用语义结构，原生 dialog、可见焦点、表单标签和 reduced-motion 规则。

官网页面与公开 CSS 已用于核对色彩、字体类别及导航和摄影方向。官网浏览器截图读取超时，因此没有将其截图记录为已取得。本站布局和 CSS 独立实现，使用 Holiday Resort 自己的品牌与示例内容。

## 本轮页面与交互

首页 `/`：摄影、日期与数量输入、酒店介绍、客房入口、泳池庭院和入住问答。

客房页 `/rooms`：后端驱动的房型目录、日期回填、分类与可用性查询、每晚基础价、可用数量、详情弹窗、400 错误与无结果状态。房型名称、价格和房号仍来自开发样例文件，不是已经冻结的团队业务数据。

日期输入按后端提供的 Asia/Shanghai 当天限制最早入住日，退房晚于入住；后端 RoomQueryService 独立重新校验日期、数量与房型。GET 参数交给后端查询内存快照，再渲染结果，不在 JavaScript 中伪造库存。当前不连接真实库存、不计算会员折扣或订单总价，也不创建 booking。

原生 dialog 用于探索导航和居所详情，支持关闭按钮与 Escape。入住说明使用原生 details，保持键盘可操作。

## 仍需接入

真实持久化数据、Booking 库存占用与事务、正式身份、预订、支付与会员。Room 管理页、查询和仅本机的临时 Session 预览已实现；不能据此声称正式认证或 booking 已完成。

来源与授权记录见 `image-credits.md`，检查过程和结果见本轮工作日志。

## 管理界面（2026-10-28）

沿用暖白底色、衬线标题、细线表格与矩形按钮。管理清单显示物理房号和占用限制，使用独立 STAFF 导航；手机表格在带名称且可聚焦的区域局部滚动，编辑表单单列排列。写入反馈由服务端返回，保留真实错误、冲突和空状态。

## 预订流程 UI（2026-10-28）

入住确认采用左侧分段表单、右侧房型摄影和入住摘要；手机为单列。详情与支付复用同一摘要，记录清单沿用照片和细线分隔。预订步骤、返回路径、明确标签、role=alert 错误和 no-store 响应保留。

开发示例页统一显示本地 UI 演示说明；动态选房只显示每晚基础价与待服务返回的最终金额。支付成功、失败、待核对和过期为固定示例链接，不伪装真实扣款、超时释放或库存预留。默认启动不展示这些入口。

## 账户与会员 UI（2026-10-28）

登录/注册桌面采用摄影与表单双栏，手机为单列；保留真实标签、空密码字段、错误提示及明确的后续返回位置。注册结果与个人中心复用细线数据列表，资料可换行。未放无效的“忘记密码”或真实付款链接。

会员页面展示未开通、有效、过期、待确认的固定状态，包含状态示例导航和开通/续费入口。会员费、规则、折扣不造数，待确认不提供重复付款。全程有本地演示标识；正式集成需要根据 A/C 输出调整文案和实际操作入口。

## 工作人员预订 UI（2026-10-29）

后台导航共享房间/预订入口并标记当前页面；列表采用细线分隔的编号/住客、住期、状态/金额与详情链接，手机重排两列信息，避免整页横向滚动。筛选有明确标签与格式说明，详情返回保持条件。预订与支付文案分开显示，状态同时使用文字，空金额为待报价。

详情以入住、联系、费用与操作四区分组，手机单列；服务未接入的状态变更与支付核对按钮禁用，并提供就近原因。演示标记贯穿页面，未加入虚构交易记录/时间线、未把用户输入作为HTML渲染。开发检查覆盖1440/390/320 CSS像素；这不替代真实用户或辅助技术验证。

## 本地收尾检查 2026年10月30日

主要内容成为显式键盘焦点目标，错误摘要在服务端校验返回后自动获取焦点，并显示轮廓；原生dialog键盘进退/归还触发位置经过开发检查。安排日期滚动读取减少动态效果偏好。39次已知页面宽度检查无整页横向溢出；详细范围和真实200%缩放等未验证项目见b-closeout.md，不据此宣称无障碍认证。
