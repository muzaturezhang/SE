# Glossary

Owner：A；新术语先定义后使用。跨模块文档只使用本表含义。

| 术语 | 含义 | 归属 |
| --- | --- | --- |
| Customer | 已注册并可登录的顾客身份，角色为 CUSTOMER。 | A |
| Member | Customer 的业务状态，表示已付费且有效的会员资格；不是管理角色。 | A |
| Staff | 团队预先提供的工作人员身份，角色为 STAFF，可管理房间与查看顾客预订。 | A |
| Visitor | 未登录的浏览者，可浏览和搜索房型，不能预订或查看个人资料。 | B/A |
| Room | 可被具体管理的物理房间，房号固定且唯一；停用保留历史，不物理删除。 | B |
| Room Type | 房型，携带每晚基础价；一笔 Booking 初版只含一个房型。 | B |
| Booking | 预订记录；由 C 编排创建、锁定、重新检查、分配与保存，并保存价格快照。 | C |
| Payment | 支付及其状态；超时或结果不明时先核对，不重复扣款、不提前释放库存。 | C |
| Reminder | 入住前提醒；默认提前 1 天，Q8 演变为 3 天与 1 天。 | D |
| Stay period | [入住日期, 退房日期) 的半开区间，Asia/Shanghai LocalDate，至少一晚。 | B |
| Base rate | 房型每晚基础价，CNY 整数分，由 B 维护；不是最终应付总价。 | B |
| Membership fee | 会员费，CNY 整数分，独立于住宿房费计算。 | A |
| Discount | 有效会员的住宿折扣比例，由 A 提供；最终计价归 C。 | A/C |
| Hold | 创建待支付 Booking 时对房间的占用，默认保留 15 分钟。 | C |
